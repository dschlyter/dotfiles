Visualise the results of this session to the user. Usually architecture and how data flows are of particular interest. Like a visualisation with boxes and lines explaining the high level view.

A suitable visualisation might be a SVG in html (and using the "datavis" skill if available).

Create the visualisation in a directory "GEX-vis" then display the absolute path in the output for the user to click on.
